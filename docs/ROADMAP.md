# 路线图

路线图是公开建设方向，不是收益或交付日期保证。

| 阶段 | 工作重点 | 验收输出 |
| --- | --- | --- |
| 0.1 公共研究预览 | 独立源码、离线示例、贡献与维护入口 | 可克隆源码、实际离线检查、清楚的版本边界 |
| 0.2 独立运行与数据契约 | 减少历史路径/协议耦合，补公开可用输入说明 | 核心功能可在干净环境独立复现、缺失输入可定位 |
| 0.3 因子与战法实验 | 有界候选、失败台账、独立时序比较 | 逐候选通过/淘汰/不足结论及可复核结果 |
| 0.4 执行与前向观察 | 共享资金、成本、取消/未成交与人工延迟 | 冻结协议后的真实观察记录及限制 |

欢迎贡献：输入模式、单位和时点验证；算子与统计缺陷；公共夹具和离线用例；策略规则的精确定义；文档及桌面工作台体验。用 Issue 讨论需求，按贡献指南提交具体 PR。
