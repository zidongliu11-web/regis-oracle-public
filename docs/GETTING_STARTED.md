# 开始使用

## 离线研究核心

Python 3.12 是首发检查环境。创建独立虚拟环境后安装 requirements-dev.txt，运行 README 中的示例、pytest 和发布检查。依赖版本范围与首次实际检查环境分开记录在 [版本边界](PUBLIC_EDITION.md)。

examples/offline_factor_demo.py 不读取账户、真实行情、密钥或本地研究缓存，不启动采集与搜索。默认 pytest 只运行公共版纳入的合成数据回归用例；其他研究工具应按各自输入要求单独验证。

## 桌面工作台原型

安装额外依赖，再启动仅监听本机的工作台：

~~~bash
python -m pip install -r requirements-app.txt
python scripts/run_local_preview.py --port 8775
~~~

打开 http://127.0.0.1:8775/factor-system 。公共版入口默认关闭后台监控与前向采集。不要使用 --research-history：该选项属于原型兼容入口，需要另外配置、审核并授权自己的数据。

工作台源码不是托管行情服务。行情适配入口可能向第三方源发起请求；调用前核查其当前条款和使用许可。只有离线示例和公共版指定回归用例属于默认离线检查范围；安装 app 额外依赖不证明所有页面/API 可用。

## 数据接入

公开仓库不附带市场历史、研报、账户记录或已批准策略。查看 [数据契约](DATA_CONTRACT.md)，建立自己的合法输入，然后按时点、覆盖、费用与执行条件逐层验证。不要用合成面板、当前名单或未经验证的缓存替代历史真实数据。

## 常见情况

| 情况 | 含义与处理 |
| --- | --- |
| 因子数量为零/登记不存在 | 公共版没有带出内部因子登记；需要自己的研究及登记 |
| 工作台显示数据缺失 | 对应功能尚未获得满足契约的输入 |
| 可导入模块但某工具找不到协议 | 扩展工具源码可能依赖未公开的历史研究文件；先建立独立公开协议 |
| 测试通过 | 只说明指定用例的工程行为；不代表策略经济有效 |
| Windows 无法激活 venv | 可以直接用 .venv\Scripts\python.exe 运行命令，无需改变系统执行策略 |
