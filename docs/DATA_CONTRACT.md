# 数据契约

代码许可证与数据许可分别处理。默认离线示例只使用程序生成的虚构数据。

接入真实数据时，至少记录：

| 项目 | 必须明确的内容 |
| --- | --- |
| 来源与权限 | 提供者、接口/文件版本、允许用途、留存与再分发条款 |
| 时点 | 事件时间、源发布时间、取得时间、策略决策时可见性 |
| 证券身份 | 六位代码与交易所、上市实例、历史代码变化与退市处理 |
| 覆盖 | 历史日期、实际证券数量、缺失、停牌、ST 与异常输入 |
| 价格 | 原始价/复权价、复权因子、除权行动、涨跌停参考价 |
| 金额与单位 | 成交量股/手、成交额元/万元、财务口径及报告期 |
| 质量与复现 | 文件哈希、模式、重复、缺失、解析失败与排除记录 |

真实行情及公告的授权并不会因为接口可访问而自动成立。当前成分、行业与公司名称不能无说明地回填历史；事后数据不能用于盘中决定。

公共版不提供全 A 历史覆盖、长期授权、历史盘口或真实成交保证。数据准入仍需独立核查。
