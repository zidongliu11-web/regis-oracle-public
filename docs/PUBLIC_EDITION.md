# 公共版范围

版本：0.1.0-public-preview。独立源码快照，不包含原研发仓库的 Git 历史。

## 纳入

- 因子系统、A 股规则与统计、研究工具、桌面工作台及辅助组件源码。
- 程序生成的离线示例和精选合成数据回归用例。
- README、架构、贡献指南、数据与研究标准、维护模板和自动检查。

## 未纳入

- 账户、Token、环境配置、数据库、行情/PIT 面板、研报/PDF。
- 内部交接、历史实验合同与结果、原机器运行目录。
- 已批准的交易模型、券商执行与生产部署。

## 支持边界

首发重点支持离线核心示例与指定 pytest 用例。工作台/扩展工具源码开放供研究和贡献，不承诺所有路径已独立可运行；部分依赖历史协议或登记，公共版尚未提供。

代码沿用既有通用实现，其中历史注释、UI 标签、阈值、研究日期及“内置因子”命名不构成当前验证结论。README 与本版本验证说明对公开能力的界定优先；后续通过小范围 PR 清理历史耦合。

Python 3.12.14 是本地检查解释器。首次本地核心包版本：numpy 2.3.5、pandas 3.0.1、scipy 1.18.1、pytest 9.1.1。requirements.txt 设兼容范围，GitHub Actions 在独立环境安装后检查；范围内所有版本组合并未逐一测试。

Kronos 模型源码片段按上游 MIT 许可保留，未附权重，未验证公共版推理；其依赖不属于离线核心。历史 FinHack 派生目录因求值引擎缺失及分发来源待核，公开版本以空兼容模块替代。核心示例不依赖这些组件。

## 可核对的检查

- 发布扫描：禁止文件类别、明显密钥模式、个人机器路径、Python 语法与文档本地链接。
- 离线示例：虚构面板的因子计算与处理。
- 回归用例：价格表示、A 股规则、合成面板的回测与中性化等指定工程行为。

扫描不证明绝对无秘密或数据权利，指定工程测试不代表全部源代码测试或交易有效。Actions 徽章反映实际远端运行状态；未运行的功能不写成通过。

## 维护方式

小范围 PR → 对应实际检查 → 维护者审核 → 更新 CHANGELOG。新输入、协议或依赖发生实质变化时重新验证。原研发库继续独立私有；后续公开变更通过审阅后的源码快照或公开 PR 进入本仓库。
